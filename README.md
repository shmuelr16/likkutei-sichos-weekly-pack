# 📚 חבילת לימוד שבועית – ליקוטי שיחות

סקיל (Skill) ל-Claude שמקבל שיחה מליקוטי שיחות על פרשת השבוע ומכין ממנה ארבעה דברים:

| | מה מקבלים |
|---|---|
| 💬 | **הסבר פשוט** בצ׳אט, לפי סדר השיחה, ובסוף מבחן קצר אם רוצים |
| 📄 | **דף לימוד דו״צ** (PDF): מפת דף, שורות ״בקצרה״, ציורים קטנים ומילון מילים קשות |
| 🎞️ | **מצגת PowerPoint מונפשת**: כרטיסים שנכנסים בלחיצה, מעברים, ושקף ״וואו״ בסוף |
| 🎬 | **סרטון של 4 דקות בערך** עם קריין בעברית מ-ElevenLabs, מסונכרן לשקפים |

> הסקיל עובד **רק** על ליקוטי שיחות ופרשת השבוע. הוא לוקח **רק** מה שכתוב בשיחה, בלי להוסיף רעיונות מבחוץ.

---

## 🤔 מה זה בכלל ״סקיל״?

סקיל הוא קובץ הוראות ש-Claude קורא לפני שהוא מתחיל משימה. אחרי שמתקינים אותו, Claude כבר יודע איך לבנות את כל החבילה: באיזה סדר, באיזה עיצוב, ואילו טעויות להימנע מהן. לא צריך להסביר לו כל שבוע מההתחלה.

## 🛠️ התקנה

### אפשרות 1: באפליקציה או באתר של Claude (הכי פשוט)

1. למעלה בדף לוחצים על **Code** ← **Download ZIP**, ופותחים את הקובץ שירד.
2. בתוך התיקייה שנפתחה יש תיקייה בשם **`likkutei-sichos-weekly-pack`**. דוחסים **רק אותה** לקובץ ZIP (במק: קליק ימני ← Compress).
   > חשוב: שם התיקייה בתוך ה-ZIP חייב להיות בדיוק `likkutei-sichos-weekly-pack`.
3. ב-Claude נכנסים ל-**Customize ← Skills**, לוחצים על **+** ← **Create skill** ← **Upload a skill**, ומעלים את ה-ZIP.
4. מוודאים שב-**Settings ← Capabilities** מופעל **Code execution and file creation** (בממשק החדש: **Create and edit files**).

[המדריך הרשמי של Anthropic להתקנת סקילים](https://support.claude.com/en/articles/12512180-use-skills-in-claude)

### אפשרות 2: Claude Code

```bash
git clone https://github.com/shmuelr16/likkutei-sichos-weekly-pack.git
mkdir -p ~/.claude/skills
cp -r likkutei-sichos-weekly-pack/likkutei-sichos-weekly-pack ~/.claude/skills/
```

סקיל שהותקן באפליקציה נטען גם ב-Claude Code, כשמתחברים עם אותו חשבון.

### מה עוד צריך

| | בשביל מה | חובה? |
|---|---|---|
| Claude עם יצירת קבצים | כל התוצרים | ✅ |
| חיבור (Connector) של **ElevenLabs** | הקריינות לסרטון | רק בשביל הסרטון |
| חשבון ElevenLabs עם קרדיטים | הקריינות (בערך 2,700 קרדיטים לשיחה) | רק בשביל הסרטון |
| PowerPoint או Keynote | להציג את המצגת | ✅ |

## 😴 פרומפט לעצלנים (כמוני)

מצרפים את ה-PDF של השיחה ומדביקים:

```
תפעיל את הסקיל likkutei-sichos-weekly-pack על השיחה המצורפת.
תכין לי הכל: הסבר פשוט, דף לימוד דו"צ, מצגת מונפשת וסרטון עם קריין.
תשמור הכל בתיקייה על שולחן העבודה. יאללה.
```

**עוד יותר עצלן?** אפשר לכתוב רק:

```
סקיל ליקוטי שיחות, הכל, על הקובץ הזה 🙏
```

רוצים רק חלק מהחבילה? לדוגמה:

- `רק דף לימוד, ממש קל להבנה`
- `רק מצגת לשיעור בישיבה`
- `תבחן אותי פה בצ'אט`

## 💡 טיפים

- **לקראת השקף האחרון במצגת** שואלים את הבחורים: ״שמתם לב למשהו שהשתנה לאורך כל המצגת?״, מחכים כמה שניות, ורק אז לוחצים. ככה ה״וואו״ עובד הכי טוב 😉
- את המעברים המיוחדים (וילון, דף שמתהפך) רואים במלואם רק ב-**PowerPoint**. ב-**Keynote** הם מתחלפים בדחיפה או בדהייה.
- הקריין יכול לפעמים ״לנשום״ במקום לא צפוי. זה רגיל אצל קולות AI. מבקשים מ-Claude לתקן ומציינים באיזו דקה.
- אם יש סינון אינטרנט (נטפרי וכו׳) והורדה מ-ElevenLabs נחסמת, Claude יפתח את הקובץ ב-Chrome. מורידים אותו ומצרפים לצ׳אט.
